# lodicky-projekt
Battleship Game (Lodíčky)  Školský projekt vytvorený v spolupráci so spolužiakom pomocou JavaScriptu.  Táto aplikácia implementuje klasickú hru Lodíčky, v ktorej hráči umiestňujú svoje lode na hraciu plochu a následne sa snažia potopiť lode súpera. Projekt bol vytvorený s cieľom precvičiť si prácu s JavaScriptom.
